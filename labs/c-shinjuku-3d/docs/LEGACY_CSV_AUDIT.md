## 3. 与官方数据的核对

**都营两线（可完全核对）。** 旧文件的都営新宿線 373 行、都営大江戸線 788 行，与 2026-11-14 取得的都营 ODPT 开放数据（令和7年3月15日改正版）按「日种 + 时刻 + 行先」比对：**1,161 / 1,161 行全部一致，0 条不匹配**。大江户线方向标签的对应也由此确定：`六本木・大門` = 内回り（`toei:oedo:inner-loop`），`都庁前・光が丘` = 外回り（`toei:oedo:outer-loop`）。

**京王新线（候选匹配）。** 357 行中有 317 行，可以在 0–2 分钟内、行先相同地对上都营西行直通列车到达 S01 的时刻（如京王新线 10:05 区間急行 橋本 ↔ 都营 913T 10:03 到）。这只是时刻 + 目的地的推断，标为 `candidate_through_train_unverified`，不升级为已验证。
