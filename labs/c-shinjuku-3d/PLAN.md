# PLAN · SENKIRO Lab · Shinjuku Station 3D

写于动手实现之前（2026-11-11），不超过一页。

## 目标

一个可在浏览器中旋转、逐层查看、演示站内导航的新宿站多楼层**示意**模型。
拓扑（楼层顺序、元素归属、连通关系）尽量准确；坐标、尺寸、高度一律示意并标注。

## 范围

- **建模**：JR 东日本新宿站（B1F / 1F / 2F），加一个相连站区：京王线新宿站（B1F / B2F）。
- **只画抽象体块并标「未核实」**：小田急、东京地铁丸之内线、都营新宿线·京王新线、都营大江户线、バスタ新宿。
- **不画**：西武新宿站、新宿三丁目站（它们是别的车站，只在说明里写明不在范围内）。

## 资料策略

1. 先核实任务书给的链接；打不开的记入 REPORT「与任务书的事实出入」。
2. 官方构内图只作阅读参考：不存入仓库、不描摹，几何全部自己重画成矩形示意。
3. 每个元素记录：来源、资料日期（as-of）、existence（是否核实存在）、geometry_confidence。
4. 许可不清楚或禁止再分发的数据集（如 ODPT チャレンジ限定数据）一律不用，写进待决事项。

## 纵向切片顺序

1. `data/manual/*.ts` 手工录入 → `npm run data:build` 校验并生成 `data/processed/*.json`。
2. `src/domain/`：类型、校验（改札内外只能经 Gate 相连等）、由同一份数据生成寻路图、寻路。
3. 一条演示路线跑通（出入口 → 检票口 → 站台），单元测试覆盖。
4. 3D 视图（React Three Fiber）与 2D 楼层图读同一份数据；路线高亮。
5. 交互：单层/全层、楼层剥离、外壳透明度、重置视角、按缩放分级的标签。
6. 运行动态叠加层接口 + 醒目标注的「示例模式」。
7. Playwright：canvas 存在且无控制台错误。
8. 文档：README / DECISIONS / SOURCES（含元素来源核对表）/ REPORT。
